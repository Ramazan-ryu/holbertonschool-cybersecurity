# Granite Peak Energy Cloud Assessment

This project contains the assessment plan, architecture-to-build reconciliation, calibrated findings, evidence chain, remediation plan, and client report for the M16 cloud assessment capstone.

## Deliverables

- `0-assessment_approach.md` — risk-led assessment order, deferred work, and pivot triggers.
- `1-reconciliation.md` — documented claims compared with infrastructure and exported state.
- `2-findings.md` — rated findings and explicit clearance of sound but alarming controls.
- `3-chain.md` — evidence for the cross-account deployment-to-telemetry path.
- `4-remediation/4-fix.md` — selected chain cut and operational cost.
- `4-remediation/4-chain_broken.txt` — post-fix chain re-walk, derived from the proposed fixed state.
- `4-remediation/4-programme.md` — sequenced remediation for remaining findings.
- `5-assessment_report.md` — board summary and engineering report.
