## Drift detection and limits

Retain this record with the deployed configuration. Compare the configured identifier, provider, API version, and pin-file digest against a later deployment; differences can reveal a changed model selection or substituted provider endpoint. If a successful provider response supplies an immutable `modelVersion`, revision, snapshot, or digest, record it and compare it with later responses to detect a provider-side revision or altered model artifact. The supplied evidence has no pin-file digest, resolved version, immutable revision, or model-weight hash, so silent provider updates cannot currently be detected reliably from this record.

Even with an immutable model revision, provenance does not prove identical nondeterministic outputs or model safety. It does not attest prompt contents, tool code, runtime settings, retrieval data, or other application changes. Those must be versioned and reviewed separately.
