## Drift detection and limits

Retain this record with the deployment. Compare the configured identifier, provider, API version, and SHA-256 digest of `pin.json` against a later deployment; differences can reveal a changed model selection, pin file, or provider configuration. If a successful provider response supplies `modelVersion` or another immutable revision, record it and compare it with later responses to identify a provider-side revision change. The current evidence cannot detect a silent provider update reliably because it contains no successful provider-reported version, immutable model revision, or model-weight hash.

Even an immutable model revision would not prove identical nondeterministic outputs or model safety. This record does not attest prompt contents, tool code, runtime settings, retrieval data, or other application changes; those must be versioned and reviewed separately.
